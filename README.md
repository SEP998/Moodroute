
# MoodRoute - Mood-Based Route Recommendation System

## Project Overview
MoodRoute is a web application that recommends personalised walking routes based on the user's mood and current location.

## Live Application
Access the deployed application here:

[Launch MoodRoute](https://sep998.onrender.com)

## Features
- Mood-based route recommendations
- Interactive map with route visualisation
- Location-based route planning
- User-friendly interface
- Route rating functionality

## Technologies Used
- Python
- Flask
- HTML, CSS and JavaScript
- OpenStreetMap
- Render for deployment

## How to Use
1. Open the live application.
2. Allow location access.
3. Select your current mood.
4. View the recommended route.
5. Follow the route on the interactive map.

## Deployment
The application is deployed on Render.
